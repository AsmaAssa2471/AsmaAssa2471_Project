# 🛒 E-Commerce Web Application (Core PHP & MySQL)

A simple, user-friendly e-commerce website I built using **Core PHP**, **MySQL**, and **Bootstrap 5**.

---

## 🌟 What This Project Does

### **For Customers**
* Browse items organized by category.
* View full product details, photos, and specs.
* Add items to a dynamic shopping cart.

### **For Admins**
* Secure login system for store managers.
* Easily add new products with custom image uploads.
* Edit details, update prices, or remove items from stock.

---

## 🛠️ Built With
* **Backend:** PHP 8
* **Database:** MySQL (managed via phpMyAdmin)
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
* **Server Environment:** XAMPP

---

## 🚀 How to Set Up & Run

1. Copy the project folder to your XAMPP directory:
   `C:\xampp\htdocs\AsmaAssa2471_Project`
2. Start Apache and MySQL in XAMPP Control Panel.
3. Open `http://localhost/phpmyadmin/` in your browser and create a database named `verdant_tech_db`.
4. Import the `database.sql` file into your new database.
5. Visit the storefront at:
   `http://localhost/AsmaAssa2471_Project/`
6. Access the admin login at:
   `http://localhost/AsmaAssa2471_Project/admin/login.php`
